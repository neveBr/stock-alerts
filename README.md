# Stock Alerts 📈

## מה מקבלים
- **מניות ברשימה שלך (עד 1000):** כל ידיעה חדשה (🔴 גבוה / 🟡 בינוני / ⚪ נמוך) + התראה על תנועה של 5%+ ביום. מחירים נבדקים לכל המניות בכל הרצה; חדשות נבדקות ל-120 מניות בכל הרצה בסבב (עד 120 מניות = כולן בכל הרצה; ב-1000 מניות כל מניה בערך כל 20 דקות).
- **🚨 חדשות קריטיות על כל חברה בשוק:** מיזוגים ורכישות, פשיטת רגל, אישורי FDA, עצירת מסחר, הורדת תחזית, התפטרות מנכ"ל, האשמות SEC, **חוזים גדולים (100 מיליון $ ומעלה)**. עד 10 התראות כאלה בכל בדיקה. רק ממקורות פיננסיים רציניים, בלי ספאם של משרדי עורכי דין.
- **🌍 חדשות שוק ו-🏭 סקטורים:** החלטות ריבית של הפד, אינפלציה, נתוני תעסוקה, תוצר, מכסים, הגבלות ייצוא, סנקציות, OPEC ומחירי נפט, השבתת ממשל, תשואות אג"ח, תנועות חדות בשוק, קריפטו ורגולציה. כל התראה מציינת על איזה סקטור היא משפיעה. כברירת מחדל נשלחות רק חדשות על הסקטורים של המניות ברשימה שלך (הסקטור של כל מניה נלקח מ-Yahoo), וחדשות על השוק כולו תמיד נשלחות. רק מ-Reuters, Bloomberg, CNBC, WSJ, FT, MarketWatch, Barron's ו-AP, ובלי כתבות דעה או "מניות לקנות".

## איך נראית התראה
כותרת מתורגמת לעברית, הסבר קצר של משפט או שניים (כשהמקור מספק תקציר), ומתחת קישור לכתבה המקורית. ככה אפשר להחליט אם להיכנס בלי לפתוח כל לינק. `/lang en` מחזיר לאנגלית.

## התקנה על Mac (אפליקציה שרצה ברקע)
1. מורידים את **StockAlerts.dmg** מ-[Releases](https://github.com/neveBr/stock-alerts/releases/latest), פותחים אותו וגוררים את **Stock Alerts** ל-Applications.
2. פותחים את האפליקציה. בפעם הראשונה macOS יגיד שהיא ממפתח לא מזוהה: **System Settings ← Privacy & Security ← Open Anyway** (במערכות ישנות יותר: לחיצה ימנית ← Open).
3. מדביקים את הטוקן של הבוט, שולחים `/start` לבוט בצ'אט הפרטי ובקבוצה, והאפליקציה מוצאת את הצ'אטים לבד. מגיעה הודעת בדיקה לטלגרם.

מכאן הבוט עולה לבד בכל כניסה ל-Mac, בודק חדשות כל 2 דקות ועונה לפקודות תוך שניות. המחשב צריך להיות דלוק ומחובר לאינטרנט (סגירת מכסה של לפטופ מרדימה אותו). פתיחה חוזרת של האפליקציה: עדכון / הפעלה מחדש, שינוי הגדרות טלגרם, או הסרה.

לבנייה מחדש של ה-DMG: `mac/build_dmg.sh 1.1`

## פקודות בטלגרם
| פקודה | מה עושה |
|---|---|
| `/add TSLA` | הוספת מניה |
| `/add TSLA AAPL NVDA` | הוספת כמה מניות בבת אחת (רווחים, פסיקים או שורות, עד 1000) |
| `/add TSLA=Tesla Motors` | הוספה עם שם לחיפוש |
| `/remove TSLA AAPL` | הסרת מניה אחת או כמה |
| `/remove all` | ריקון הרשימה |
| `/list` | הרשימה + מחירים |
| `/market on` / `/market off` | חדשות קריטיות על חברות + חדשות שוק וסקטורים |
| `/sectors mine` | חדשות סקטור רק על הסקטורים של המניות שלך (ברירת מחדל). חדשות על השוק כולו תמיד נשלחות |
| `/sectors all` | חדשות על כל הסקטורים |
| `/level 1` / `2` / `3` | כמה חדשות לשלוח על הרשימה (1 = הכול, 3 = רק אירועים גדולים) |
| `/lang he` / `/lang en` | שפת הכותרות וההסברים (עברית / אנגלית) |
| `/status` | האם הבוט רץ, על איזה מחשב, ומתי הייתה הבדיקה האחרונה |
| `/help` | עזרה |
