# Stock Alerts 📈

התראות לטלגרם על חדשות שיכולות להזיז מניות. רץ בענן על GitHub Actions כל ~5 דקות, גם כשהמחשב כבוי.

## מה מקבלים
- **מניות ברשימה שלך (עד 1000):** כל ידיעה חדשה (🔴 גבוה / 🟡 בינוני / ⚪ נמוך) + התראה על תנועה של 5%+ ביום. מחירים נבדקים לכל המניות בכל הרצה; חדשות נבדקות ל-120 מניות בכל הרצה בסבב (עד 120 מניות = כולן בכל הרצה; ב-1000 מניות כל מניה בערך כל 45 דקות).
- **🚨 חדשות קריטיות על כל חברה בשוק:** מיזוגים ורכישות, פשיטת רגל, אישורי FDA, עצירת מסחר, הורדת תחזית, התפטרות מנכ"ל, האשמות SEC, **חוזים גדולים (100 מיליון $ ומעלה)**. עד 10 התראות כאלה בכל בדיקה. רק ממקורות פיננסיים רציניים, בלי ספאם של משרדי עורכי דין.
- **🌍 חדשות שוק ו-🏭 סקטורים:** החלטות ריבית של הפד, אינפלציה, נתוני תעסוקה, תוצר, מכסים, הגבלות ייצוא, סנקציות, OPEC ומחירי נפט, השבתת ממשל, תשואות אג"ח, תנועות חדות בשוק, קריפטו ורגולציה. כל התראה מציינת על איזה סקטור היא משפיעה (שבבים, אנרגיה, בנקים, מחצבים, רכב ועוד). רק מ-Reuters, Bloomberg, CNBC, WSJ, FT, MarketWatch, Barron's ו-AP, ובלי כתבות דעה או "מניות לקנות".

## פקודות בטלגרם
| פקודה | מה עושה |
|---|---|
| `/add TSLA` | הוספת מניה |
| `/add TSLA AAPL NVDA` | הוספת כמה מניות בבת אחת (רווחים, פסיקים או שורות, עד 1000) |
| `/add TSLA=Tesla Motors` | הוספה עם שם לחיפוש |
| `/remove TSLA AAPL` | הסרת מניה אחת או כמה |
| `/remove all` | ריקון הרשימה |
| `/list` | הרשימה + מחירים |
| `/market on` / `/market off` | חדשות קריטיות על חברות + חדשות שוק וסקטורים |
| `/level 1` / `2` / `3` | כמה חדשות לשלוח על הרשימה (1 = הכול, 3 = רק אירועים גדולים) |
| `/help` | עזרה |

> הפקודות מתבצעות בהרצה הבאה, כלומר עד ~5-10 דקות.

## הגדרה ב-GitHub
1. Settings → Secrets and variables → Actions → New repository secret:
   - `TELEGRAM_BOT_TOKEN`: הטוקן מ-BotFather
   - `TELEGRAM_CHAT_IDS`: ה-IDs, מופרדים בפסיק (למשל `123456789,-1001234567890`)
2. לשונית Actions → **Stock news alerts** → Run workflow (הרצה ראשונה).

## הרצה מקומית (לא חובה)
יוצרים `local_secrets.json` (הקובץ לא נשמר ב-git):
```json
{"telegram_bot_token": "...", "telegram_chat_ids": ["..."]}
```
```bash
python3 stock_news.py --loop
```

## קבצים
- `stock_news.py`: כל הלוגיקה (Python רגיל, בלי התקנות)
- `watchlist.json`: רשימת המניות וההגדרות (מתעדכן דרך טלגרם)
- `state.json`: אילו ידיעות כבר נשלחו (נשמר ב-Actions cache, לא ב-git)
- `.github/workflows/watch.yml`: התזמון בענן
